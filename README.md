# ALU Simulator Using Assembly Language
A practice project for Computer Architecture subject where we use Assembly Language to implement ALU simulator that contains the following two features 1- Allowing user to choose between two numbering systems (Binary &amp; Hex) 2-Doing complex calculations and produce the result including overflows
